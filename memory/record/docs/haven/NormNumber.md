# NormNumber

Represents the norm number Haven component.

## Nested Types

### MNorm16

- Role: Stores a modular normalized 16-bit value.
- Description: Number wrapper that maps a 16-bit modular value to the 0..1 range.

### MNorm32

- Role: Stores a modular normalized 32-bit value.
- Description: Number wrapper that maps a 32-bit modular value to the 0..1 range.

### MNorm8

- Role: Stores a modular normalized 8-bit value.
- Description: Number wrapper that maps an 8-bit modular value to the 0..1 range.

### SNorm16

- Role: Stores a signed normalized 16-bit value.
- Description: Number wrapper that maps a signed short to the -1..1 range.

### SNorm32

- Role: Stores a signed normalized 32-bit value.
- Description: Number wrapper that maps a signed int to the -1..1 range.

### SNorm8

- Role: Stores a signed normalized 8-bit value.
- Description: Number wrapper that maps a signed byte to the -1..1 range.

### UNorm16

- Role: Stores an unsigned normalized 16-bit value.
- Description: Number wrapper that maps an unsigned short to the 0..1 range.

### UNorm32

- Role: Stores an unsigned normalized 32-bit value.
- Description: Number wrapper that maps an unsigned int to the 0..1 range.

### UNorm8

- Role: Stores an unsigned normalized 8-bit value.
- Description: Number wrapper that maps an unsigned byte to the 0..1 range.
